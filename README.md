# itd-frontend
[![AI-DECLARATION: auto](https://img.shields.io/badge/䷼%20AI--DECLARATION-auto-ede9fe?labelColor=ede9fe)](https://ai-declaration.md)

Автоматический парсер, декомпилятор и трекер изменений фронтенда платформы [ИТД](https://xn--d1ah4a.com) (итд.com).

## 🚀 Возможности

- **Обход DDoS-Guard**: автоматическое решение JS-челленджа (`_get_jhash`) и поддержка авторизованной сессии с куками.
- **Полное скачивание ассетов**:
  - Базовые скрипты и стили, подключенные напрямую в `index.html`.
  - Динамические модули и lazy-loaded страницы из карты зависимостей Vite (`__vite__mapDeps`).
  - Служебные импорты (API медиасообщений, маршрутизаторы, модальные окна, утилиты).
  - Структурирование по модулям (`raw/<страница>/` и `raw/` для общих файлов).
- **Декомпиляция JavaScript**:
  - Быстрая деминификация и восстановление читаемости кода через [Wakaru](https://github.com/pionxzh/wakaru) v1.x (Rust CLI).
  - Многопоточная обработка бандлов.
- **Форматирование CSS**: структурирование стилей с отступами и форматированием селекторов.
- **Извлечение SVG**:
  - Автоматическое извлечение встроенных React/JSX SVG-компонентов в автономные валидные `.svg` файлы (`decompiled/svg/`).
  - Поддержка фрагментов, тернарных операторов и условий.
  - Дедупликация и нормализация атрибутов (camelCase -> kebab-case).
- **Просмотр различий (`diff.py`)**:
  - Полноэкранный TUI на базе Textual (`textual-diff-view`) с поддержкой бок-о-бок и объединенного режимов.
  - Поддержка CLI-вывода (`--cli`) для вывода цветного diff в терминал.
  - Автоопределение измененных файлов в Git.
- **Автоматический трекер (`update.py`)**:
  - Периодический запуск по расписанию (по умолчанию каждые 2 часа).
  - Автоматическое создание коммитов `autosave at DD.MM HH:MM` при обнаружении изменений.
  - Поддержка отправки в удаленный репозиторий (`git push`).

## 📁 Структура проекта

```
itd-frontend/
├── raw/                # Исходные скачанные файлы с сервера (JS, CSS)
├── decompiled/         # Декомпилированные и отформатированные файлы
│   └── svg/            # Извлеченные SVG-иконки
├── main.py             # Основной скрипт парсинга, скачивания и декомпиляции
├── svg_extractor.py    # Модуль парсинга и извлечения SVG из JSX/React
├── diff.py             # TUI / CLI инструмент просмотра диффов между версиями
├── update.py           # Фоновый демон для обновления по расписанию
├── requirements.txt    # Python зависимости
└── package.json        # Node.js зависимости (@wakaru/cli)
```

## 🛠 Установка

### 1. Системные требования
- **Python** 3.10+
- **Node.js** 18+ (для работы декомпилятора Wakaru)
- **Git**

### 2. Установка зависимостей Python
```bash
python -m venv .venv
# Windows:
.\.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Установка Node.js зависимостей
```bash
npm install
```

## 💻 Использование

### Сбор и декомпиляция фронтенда
Запуск единоразового полного цикла скачивания, декомпиляции и извлечения ассетов:
```bash
python main.py
```

### Запуск демона автообновления
Запуск планировщика для отслеживания изменений каждые 2 часа:
```bash
python update.py
```

Параметры:
- `-s`, `--single`: разовый запуск без ожидания планировщика.
- `-i <hours>`, `--interval <hours>`: интервал проверки в часах (например, `-i 1.5`).
- `--no-push`: коммитить локально, не отправлять в удаленный git-репозиторий.

Пример:
```bash
python update.py -s --no-push
```

### Просмотр изменений (Diff Viewer)

1. **Автоопределение измененных файлов**:
```bash
python diff.py
```
Откроет TUI для первого измененного файла либо выведет список всех изменений.

2. **Сравнение конкретного файла с последним коммитом в Git**:
```bash
python diff.py decompiled/index-B4ySybtH.js
```

3. **Сравнение двух файлов напрямую**:
```bash
python diff.py decompiled/old.js decompiled/new.js
```

4. **Вывод diff в консоль (без TUI)**:
```bash
python diff.py decompiled/index-B4ySybtH.js --cli
```
